# 👹 高校入試対策シリーズ ～大問2・一次方程式～

一次方程式を、式の構造から判断して練習する静的Webアプリです。過去問本文・図・固有データは掲載せず、独自のパラメータから問題を生成します。

## できること

- 整数係数の一次方程式を1セット10問出題
- 3項の式を3問、両辺に文字がある4項の式を7問出題
- 段階的に表示される計算過程つきヒント
- 分数入力、全角数字の半角変換、正誤表示と正解時の演出
- 同じseedなら問題・答え・解説を再現できる生成器

## ローカル確認

静的ファイルをローカルWebサーバーで開きます。問題生成の検証は、Node.jsで次を実行します。

```sh
node qa-seed-check.mjs
```

外部通信、保存内容、第三者コンポーネントは[DEPENDENCIES.md](./DEPENDENCIES.md)と[NOTICE.md](./NOTICE.md)を参照してください。
